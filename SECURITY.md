# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, email the maintainer or open a private security advisory on GitHub
(Security → Advisories → New draft security advisory).

We will acknowledge receipt within a few days and aim to provide a fix or
mitigation as quickly as possible.
